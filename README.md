# Christmas Valley Park & Recreation — Website (Proposed Redesign)

A modern, mobile-friendly redesign of cvparkandrec.com. This is a single,
self-contained web page (`index.html`) that runs anywhere — no build steps,
no plugins.

## Live link
Once GitHub Pages is turned on (Settings → Pages → Branch: main → Save), the
site is published at:
`https://<your-username>.github.io/<repo-name>/`

## Adding real photos
See **images/PHOTO-GUIDE.txt**. Drop correctly-named photos into the
`images/` folder and commit them — they appear automatically. Until then,
elegant illustrations stand in, so the site always looks complete.

## Newspaper & minutes files
The Desert Whispers archive and the Minutes archive link to real PDFs that live
in this repo's `documents/` folder (`minutes/`, `desert-whispers/`, `gazette/`).

**Desert Whispers, 2020–2026:** These 131 recent issues (July 2020 through the
latest) were rebuilt from the District's Facebook page — each issue's pages were
scraped, combined into a single PDF, and are **already committed** in
`documents/desert-whispers/<year>/`. Nothing to download for these.

**Older issues + minutes (from the previous cvparkandrec.org site):** Run
**download-documents.command** (if macOS blocks it, right-click → Open) to fetch
the older PDFs into `documents/`. A handful of the very oldest files (some 2016,
1980–82 Desert Whispers, and pre-2017 minutes) are no longer on the old server
and will list as MISSING — that's expected; those simply aren't available.

After adding any files: in GitHub Desktop, review the new files → **Commit to
main** → **Push**. The archive links on the live site then open each real file.
