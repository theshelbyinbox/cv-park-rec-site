# Christmas Valley Park & Recreation — Website (Proposed Redesign)

A modern, mobile-friendly redesign of cvparkandrec.com. This is a single,
self-contained web page (`index.html`) that runs anywhere — no build steps,
no plugins.

## Live link
Once GitHub Pages is turned on (Settings → Pages → Branch: main → Save), the
site is published at:
`https://<your-username>.github.io/<repo-name>/`

## Adding real photos
See **images/PHOTO-GUIDE.txt**. Drop correctly-named photos into the
`images/` folder and commit them — they appear automatically. Until then,
elegant illustrations stand in, so the site always looks complete.
